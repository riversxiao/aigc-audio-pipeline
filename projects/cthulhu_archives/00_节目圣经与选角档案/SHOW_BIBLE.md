# 《克苏鲁神话·不可名状声音档案》节目制作圣经（第一季）

## 一、 节目定位与差异化亮点

- **核心定位**：直接基于 H.P. 洛夫克拉夫特（1890–1937，**全球 100% 公版**）英文原著，以**“1920s 密斯卡托尼克大学绝密蜡筒与调查档案”**为叙事框架，自主改写为电影级中文多人悬疑广播剧。
- **版权绝对干净**：严禁照搬国内现代出版社译本；全部对白、档案串联与戏剧结构均为基于英文公版原著的全新原创剧本，支持**喜马拉雅 + 小宇宙 + B站 + YouTube** 全平台同步分发。
- **声音设计绝活**：充分利用三总线混音与多空间声场——档案员与学者采用 `studio_warm` 近讲真人质感（零古风腔），蜡筒录音/临终航海日记/南极短波电报采用 `memory_echo` 复古窄带声场，旧日低语与壁画残响采用 `mental_realm` / `vast_hall` 深渊混响。
