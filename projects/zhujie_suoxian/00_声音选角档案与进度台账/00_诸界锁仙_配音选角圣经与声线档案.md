## 二、 引擎与品质铁律（对齐 `aigc-audio-pipeline` v0.4）

1. **同源五合一引擎**：统一采用 ElevenLabs 生态——原生国风捏声 `eleven_ttv_v3`（Voice Design v3 创造纯正大陆古风角色声优）、戏剧对白 `eleven_v3`（`language_code="zh"`）、动效 `eleven_text_to_sound_v3`（`prompt_influence=0.55`）、分幕纯配乐 `music_v2_5`（`force_instrumental=true`，禁止同时传 `seed`）、双语质检 `scribe_v3`（`zh` + `en` 检测标签漏读）。
2. **大陆普通话戏剧声优硬门槛（20 位原生定制 + 4 位纯净棚录库声）**：严禁使用美式、澳洲、新加坡、港台腔或存在空调底噪的克隆声线；全部 24 个在用角色声槽均通过逐条人工审听锁定。
3. **三档离散稳定性 + 行内英文标签**：
   - 平稳铺陈与克制对白：`stability = 0.5`（Natural），`similarity_boost = 0.85`。
   - 生死冲突、退婚撕契、碎丹田、开基因锁、哭喊、反派伪善低语、识海古棺现世旁白：一律打到 `stability = 0.0`（Creative），并在半句前写入英文小写方括号标签（如 `[coldly]`、`[crying]`、`[desperately]`、`[whispers]`、`[dramatically]`、`[shouting]`）。
   - 上古石碑铭文、法则天音、血尸傀儡：`stability = 1.0`（Robust），配合 `mental_realm` 或 `memory_echo` 声场。
4. **三总线自然语速母带 + `polyphones.py` 自动修仙多音字保护**：
   - 人声绝不按固定格子裁尾；动效走前景独立轨（**不随对白压低**）；分幕配乐仅在对白区间平滑闪避至 `0.11`，气口与留白回升至 `0.34`，成片统一母带校准至 `-16 LUFS`，`.srt` 字幕自动映射中文角色名（如 `【陆烬】`）。
   - `polyphones.py` 自动将 `引气一重..九重 -> 引气一崇..九崇`、`真传 -> 真船`、`忝为 -> 舔为`、`刀锷 -> 刀鄂`、`劈开 -> 批开`、`白芨 -> 白及`、`虫豸 -> 虫至`、`龟裂 -> 均裂`、`辟谷 -> 必谷`、`三更 -> 三羹` 等注入 `tts_text`，同时保留 `text` 文学正字不变。
